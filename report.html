نبذة عن المشروع والأهداف

تأتي هذه المنظومة كجزء من التوجه الاستراتيجي نحو التحول الرقمي الشامل

📄 خلفية المشروع

في إطار التوجه العام نحو التحول الرقمي وتحسين كفاءة الأداء المؤسسي، تم تطوير منظومة الأرشفة الإلكترونية CiviX. هذا التطبيق هو حل ويب متكامل مصمم خصيصاً لخدمة جميع أقسام مكتب جهاز تنفيذ المشروعات.

تعمل المنظومة على إدارة دورة حياة المشاريع الكاملة (Project Lifecycle)، بدءاً من مرحلة التعاقد، مروراً بمتابعة التنفيذ، وإدارة المستخلصات والمستندات المالية، وصولاً إلى تفويضات الصرف والإغلاق المالي النهائي. تتميز المنظومة بدعم كامل للغة العربية ونظام صلاحيات متعدد الطبقات يضمن أمان البيانات.

ملاحظة هامة: تركز المرحلة الحالية من التطوير على القسم المالي باعتباره النواة الأساسية، على أن تمتد المنظومة في المراحل القادمة لتشمل كافة الأقسام الأخرى.

🎯 الأهداف الاستراتيجية والتفصيلية

نسعى لتحقيق المعادلة الصعبة: السرعة + الدقة + الأمان.

  • الرقمنة الشاملة: توثيق جميع مراحل المشروع إلكترونياً لضمان عدم ضياع أي معلومة وتسهيل استرجاعها.
  • أتمتة العمليات المالية: تتبع المستخلصات، إصدار تفويضات الصرف، وأذونات الدفع آلياً دون تدخل ورقي معقد.
  • مركزية البيانات: إنشاء مستودع بيانات موحد يربط بين الشركات المنفذة، المهندسين المشرفين، وحالة المشاريع.
  • الأمان السيبراني: تطبيق نظام مصادقة (JWT) وتشفير (Bcrypt) لحماية البيانات الحساسة.
  • الموثوقية والاستمرارية: ضمان عمل النظام 24/7 مع نسخ احتياطية يومية تلقائية.

المنهجية والتقنيات والفريق

⚙️ منهجية العمل والبنية التقنية

منهجية Agile (Scrum/Kanban)

تم اعتماد منهجية التطوير الرشيق لتقسيم العمل إلى دورات تطويرية قصيرة (Sprints). هذا الأسلوب يسمح بالتخطيط والتنفيذ والمراجعة المتكررة، مما مكن الفريق من التكيف السريع مع المتطلبات المتغيرة وضمان جودة التسليم في كل مرحلة من مراحل المشروع الست.

آلية التكامل والتطوير (CI/CD)

تم استخدام GitHub كمستودع مركزي للكود، حيث يعمل كل عضو على فرع (Branch) خاص به ثم يدمج التغييرات. ولضمان التوافق، تم اعتماد وثائق Swagger (OpenAPI) كمرجع موحد لربط الواجهات الأمامية بالخدمات الخلفية.

Backend & API
Python 3.x لغة مرنة وقوية. FastAPI أداء عالي ووثائق تلقائية. SQLAlchemy ORM للتعامل مع قاعدة البيانات. JWT للتأمين وتشفير الرموز.
Database & Infrastructure
MS SQL Server 2019 Docker لحل مشكلة التوافق مع Ubuntu. Ubuntu 24.04 LTS Nginx
Frontend
HTML5/CSS3 JavaScript (ES6+) Modern JS without heavy frameworks. Fetch API

  • هندسة جداول الحسابات وضبط المطابقات المالية.
